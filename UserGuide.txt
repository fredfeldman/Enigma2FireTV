## 1. First-Time Setup

When you launch the app for the first time you will be taken to the **Setup** screen.

| Field | Description |
|---|---|
| Device Name | A friendly label (e.g. "Living Room Vu+") |
| Host / IP Address | Local IP of your Enigma2 receiver (e.g. `192.168.50.8`) |
| Port | HTTP port of OpenWebif — default is **80** |
| HTTPS | Enable only if your receiver is configured for HTTPS |
| Username / Password | Leave blank if your receiver has no login |

Tap **Save** (or press OK) when done. The app will connect and load your channel list.

> **Tip:** Make sure OpenWebif is installed and enabled on your receiver and that the receiver is on the same Wi-Fi network as your Fire TV.

## 2. Main Screen

The main screen is split into two panels:

- **Left panel** — bouquet (channel group) list
- **Right panel** — channel list for the selected bouquet

Each channel row shows the **channel logo (picon)** alongside the channel name when picons are available on the receiver.

### Toolbar buttons (top-right)

| Button | Action |
|---|---|
| Switch Device | Switch between configured receivers |
| EPG | Open the full EPG grid |
| Recordings | Browse recordings stored on the receiver |
| Timers | View scheduled recordings (and open AutoTimers from there) |
| Playlists | Open your saved playlists |
| Settings | Change receiver settings |
| Wake on LAN | Send a magic packet to wake the receiver |
| Screenshot | Show the current image on the receiver |

Use the **D-pad** to move between bouquets and channels. Press **OK / Select** on a channel to start playing it.

## 3. Watching Live TV

Pressing OK on a channel immediately starts playback in full-screen. The stream is delivered directly from the receiver over HTTP (port 8001).

- The **OSD** (on-screen display) appears automatically when playback starts, then fades out.
- Press **OK / Select** or **Play/Pause** at any time to show the OSD again.
- Press **Back** to stop playback and return to the channel list.

### Auto-tune last channel
When the app launches it automatically resumes the last channel you were watching. To disable this behaviour go to **Settings → Playback → Auto-tune last channel**.

## 4. OSD & Playback Controls

### Live TV OSD
Shows:
- Channel logo (picon) and channel name
- Current programme title and next programme
- Event progress bar

### Recordings OSD
Shows:
- Recording title
- Seek bar with current position and total duration
- Playlist position indicator (e.g. **2 / 5**) when playing a queue

### Seek controls (recordings only)

| Button | Action |
|---|---|
| D-pad Right | Seek forward |
| D-pad Left | Seek backward |
| OK | Confirm seek position |

### Playlist playback
When playing a playlist the player automatically advances to the next entry when the current one ends. The OSD shows your position in the queue (e.g. **3 / 7**). There is no manual skip button — use the Back button to exit and then tap a different entry in the playlist to jump to it.

## 5. EPG Guide

Open the EPG by pressing the **EPG** button in the toolbar.

- The grid shows all channels with their current and upcoming programmes.
- The channel column on the left shows each channel's **logo (picon)** and name.
- The time ruler runs across the top.
- The current time is highlighted with a vertical marker.
- Events that are **scheduled for recording or currently recording** are highlighted with a **red overlay** in the grid.

| Button | Action |
|---|---|
| D-pad Up/Down | Move between channels |
| D-pad Left/Right | Scroll backwards/forwards in time |
| OK / Select | Show programme details / tune to channel |
| Back | Close EPG and return to channel list |

## 6. Recordings

Open **Recordings** from the main screen toolbar.

The screen is split into:
- **Left panel** — list of all recordings on the receiver, sorted newest first
- **Right panel** — details of the focused recording (title, channel, date, duration, description)

### Playing a recording
Press **OK** on any recording to start playback.

### Adding a recording to a playlist
**Long-press** (hold OK for ~1 second) any recording. A dialog appears:
- Tap an existing playlist to add the recording to it.
- Tap **Create new playlist…** to make a new playlist and add the recording in one step.

### Refreshing the list
The list loads automatically when you open the screen. Press the **Refresh** button in the toolbar to reload from the receiver.

## 7. Timers

Open **Timers** from the main screen toolbar to view all scheduled and active recordings on the receiver.

- Each timer shows the channel, programme title, start/end time, and current status (scheduled, recording, done).
- The app checks for active timers **every 15 minutes in the background** and posts a device notification when a recording is about to start or is currently in progress.

> **Note:** To receive notifications you must grant the **Notifications** permission when prompted.

## 8. AutoTimers

The **AutoTimers** screen lets you manage AutoTimer rules on the receiver. An AutoTimer rule watches the EPG for events whose title contains a phrase you specify and automatically schedules a recording for any hits.

Open it from the **Timers** screen toolbar by tapping **AutoTimers**.

> **Note:** This requires the **AutoTimer plugin** to be installed on the Enigma2 receiver. If the plugin is missing the list will be empty.

### Adding a rule
1. Tap **+ Add**.
2. Enter a friendly **Name** (optional — defaults to the match phrase).
3. Enter the **Match** text — any EPG title containing this text will be recorded.
4. Optional: set **After** / **Before** times in `HH:MM` to restrict matching to a daily window.
5. Make sure **Enabled** is checked, then tap **OK**.

### Editing a rule
Tap any row to open the same editor pre-filled with the existing values.

### Enable / Disable
Tap the **Enable** or **Disable** button on a row to flip the rule's state without deleting it.

### Delete
Tap **Delete** on a row and confirm.

### Scan now
Tap **Scan now** in the toolbar to make the receiver immediately scan its EPG and create timers for any matching events. New timers (if any) appear on the regular **Timers** screen.

## 9. Playlists

### Opening Playlists
Tap **Playlists** in the main screen toolbar.

### Creating a playlist
1. Tap **New Playlist**.
2. Enter a name and press **Create**.

### Adding content to a playlist

**From Recordings:**
- Go to **Recordings**, long-press any recording, and pick a playlist.

**From the video folder (`/media/hdd/video`):**
1. Open a playlist (tap it in the Playlist Manager).
2. Tap **Add Video Files**.
3. The app fetches all video files from `/media/hdd/video` on the receiver.
4. Tap any file to add it to the playlist. A confirmation toast appears.
5. Press **Back** to return to the playlist — your additions are saved immediately.

### Managing playlist entries
Inside a playlist detail screen:

| Control | Action |
|---|---|
| Tap an entry | Play from that entry (queue continues to the end) |
| ▲ button | Move entry up |
| ▼ button | Move entry down |
| ✕ button | Remove entry from playlist |
| ▶ Play All | Play from the beginning |
| Add Video Files | Browse `/media/hdd/video` and add files |

### Renaming or deleting a playlist
From the **Playlist Manager**, long-press any playlist to get options for **Rename** or **Delete**.

## 10. Multiple Devices

You can configure as many Enigma2 receivers as you like.

### Adding a new device
1. Tap **Switch Device** on the main screen.
2. Tap **Add Device**.
3. Fill in the device details and tap **Save**.

### Switching devices
1. Tap **Switch Device**.
2. Tap the receiver you want to use. The app reconnects immediately.

### Editing or deleting a device
From the **Switch Device** screen, long-press any device entry for **Edit** or **Delete** options.

> **Note:** You cannot delete the last configured device. The most recently used device is reconnected automatically on next launch.

## 11. Settings

Open **Settings** from the main screen toolbar.

### Receiver Connection

| Setting | Description |
|---|---|
| Host | IP address or hostname of the active receiver |
| Port | OpenWebif HTTP port (default 80) |
| HTTPS | Use HTTPS instead of HTTP |

### Authentication

| Setting | Description |
|---|---|
| Username | HTTP Basic Auth username (leave blank if none) |
| Password | HTTP Basic Auth password (leave blank if none) |

### Receiver

| Setting | Description |
|---|---|
| Box info | Show the receiver's brand, model, image / kernel / Enigma2 / WebIF versions, uptime, MAC address, tuners, hard disks, and network interfaces. Read-only. |

### Bouquets

| Setting | Description |
|---|---|
| Hidden Bouquets | Choose bouquets to hide from the channel list |

### Appearance

| Setting | Description |
|---|---|
| Night Mode | Toggle dark/light theme |

### Playback

| Setting | Description |
|---|---|
| Auto-tune last channel | When enabled (default), the app automatically resumes the last watched channel when launched. Turn off to always start at the channel list. |
| Tune receiver to channel | When enabled (default), picking a channel in the app also retunes the Enigma2 receiver to it. Turn off to keep the receiver on whatever it was playing — useful if someone else is watching live on the box. |

### About

| Setting | Description |
|---|---|
| App version | Shows the installed app version and build code. |

Changes take effect immediately — the app reinitialises the API connection after saving.
